# NeonClick

Un auto clicker petit et beau pour Windows 10 et 11 : jusqu'à ~100 clics par seconde, clic gauche, droit ou molette, simple ou double, sur ton curseur ou à une position fixe, mode **Appuyer** ou **Maintenir**, 7 couleurs néon.

## Télécharger

👉 [**NeonClick.exe**](https://github.com/ayusecour-stack/neonclick/releases/latest/download/NeonClick.exe) — un seul fichier, sans installation, rien d'autre à installer.

Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires** puis **Exécuter quand même**.

Tous les logiciels d'Ayuha : https://ayuha-hub.pages.dev

> Certains jeux en ligne interdisent les auto clickers : vérifie leurs règles avant de l'utiliser.
